# 📧 Spam Mail Prediction using Machine Learning

This project implements a machine learning model that detects spam emails based on their content. By training on labeled data, the model learns to distinguish between legitimate (ham) and spam messages with high accuracy.

## 🔍 Overview

- **Input:** Email text data (`mail_data.csv`)
- **Process:** Data cleaning → Feature extraction → Model training → Evaluation
- **Output:** Predicts whether an email is spam or not

## 📁 Files Included

- `mail_data.csv` — The dataset containing labeled email messages  
- `Spam_Mail_Prediction_using_Machine_Learning.ipynb` — Jupyter Notebook with complete implementation

## 🧠 Techniques Used

- Text preprocessing
- TF-IDF vectorization
- Logistic Regression classifier
- Accuracy & evaluation metrics

## ⚙️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
